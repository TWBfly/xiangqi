# Windows 象棋桌面辅助器

面向 Windows 10、雷电模拟器和腾讯手游助手的本地象棋辅助程序。用户点击“同步并分析”后，程序读取一次当前棋盘，并通过置顶小窗口显示 Pikafish 推荐着法，例如“炮二平五”。

程序不会打开网页、不会播放语音、不会联网，也不会自动替你落子。

## 首次使用（腾讯手游助手）

1. 启动腾讯手游助手，在其中打开 JJ象棋，并进入一盘**尚未走子**的标准开局。
2. 运行 `XiangqiAssistant.exe`。
3. 点击“刷新设备”。在“采集源”优先选可用的 `ADB · ...`；如果没有 ADB，则必须选 `窗口 · JJ象棋 · 数字`，不要选腾讯手游助手启动器。
4. 选择自己执红或执黑。
5. 点击“校准棋盘”。
6. 程序先自动寻找棋盘。状态显示“自动校准成功”后，等棋盘稳定并点击“同步并分析”。
7. 如果自动定位证据不足，程序会自动打开手动拖框窗口：按住鼠标左键，从棋盘**左上角车的圆心**拖到**右下角车的圆心**后松开。端点是棋子圆心，不是棋盘外框，也不要把标题栏、按钮区拖进去。
8. 手动窗口关闭且状态显示“手动校准成功”后，点击“同步并分析”。

“搜索秒”默认是 10，可设置 1～60 秒。增加搜索时间通常能提高棋力，但会等得更久。程序会让 Pikafish 使用全部逻辑 CPU、512 MB 哈希和单主变化线；如需更快响应可把搜索时间调低。标准开局校准会根据棋子字色自动判断“我执”；字色不明确时才使用人工选择。“本次分析方”自动跟随“我执”，不需要手工选择当前行棋方。

同一棋盘皮肤、分辨率、DPI、执棋方向和采集源下只需校准一次。以后每次点击“同步并分析”都会直接复用已保存的校准模板。

雷电模拟器步骤相同；没有 ADB 时选择 `窗口 · 雷电模拟器 · 数字`。

## 对局中的提示顺序

1. 等对手落子和棋盘动画结束。
2. 点击“同步并分析”。程序只在此刻截图一次，并自动按“我执”分析。
3. 状态依次显示“正在截取当前棋盘”“正在识别当前棋盘”“已保存快照，正在分析”。
4. Pikafish 返回后显示中文建议。程序随后保持空闲，不会继续截图或判断对手是否落子。
5. 按建议手动落子。下一次轮到你时，再次点击“同步并分析”。

你可以不执行推荐着法，也可以从任意中盘开始。每次点击都以当前完整棋盘为新的独立局面，不依赖程序是否看见了中间走法。因此连续漏掉很多步、悔棋或任意摆子不会污染下一次分析。

当前快照不能唯一反推出之前的完整走法历史，所以长将、循环和重复局面的裁决信息不会自动恢复。默认搜索 10 秒，显示的是当前搜索预算内的最佳着法，不是数学意义上可证明的绝对最优解。

## 采集方式

程序依次寻找配置路径、雷电和腾讯常见安装目录、系统 PATH 中的 `adb.exe`，通过设备内部截图读取画面。找不到可用 ADB 时，程序列出可见的雷电或腾讯模拟器窗口并使用 Windows 窗口截图。

窗口截图模式下，模拟器不能最小化，也不能被其他窗口完全遮挡。ADB 模式不受窗口遮挡影响。

## 什么时候重新校准

- 更换棋盘皮肤。
- 更改模拟器分辨率。
- 更改 Windows DPI 缩放。
- 从执红改成执黑，或反向改变。
- 更换模拟器或截图来源。
- 当前棋盘无法识别且提示置信度过低；先排除遮挡和动画，仍失败再重新校准。

校准数据保存在 `%APPDATA%\XiangqiAssistant`。

## 从源码运行

```bat
python -m pip install -r requirements.txt
python app.py
```

## 构建 Windows EXE

在 Windows 10 中双击 `build_exe.bat`，或在命令提示符运行：

```bat
build_exe.bat
```

生成文件位于 `dist\XiangqiAssistant\XiangqiAssistant.exe`。发布或复制时必须保留整个 `dist\XiangqiAssistant` 目录，不能只复制其中的 EXE。这是无控制台的 Tkinter 桌面程序，不启动 Flask 或浏览器。
Pikafish 也以 Windows 无控制台模式运行，只通过程序内部管道通信，不会再弹出黑色命令行窗口。

## 常见错误

- **未找到模拟器**：先启动模拟器，再点击“刷新设备”。
- **自动校准失败并弹出拖框**：这不是程序终止，而是自动定位没有同时确认上下两排各 9 个棋子；按提示手动拖一次即可。
- **标准开局校准失败**：确认棋局尚未落子；手动拖框的两个端点必须位于左上车、右下车的圆心。
- **棋盘矩形超出截图范围**：拖框端点太靠近截图边缘，或选错了采集源。重新选择完整的 JJ象棋窗口，并把端点落在棋子圆心。
- **一直显示两条杠**：确认棋盘动画已经结束，然后点击“同步并分析”；程序不会自主等待或检测对手落子。
- **正在分析**：等待当前搜索完成，或点击“停止分析”。旧任务真正结束后才能再次同步。
- **无法识别当前棋盘**：关闭弹窗、棋子移动动画和其他遮挡后再次点击；仍失败时重新校准。
- **识别置信度过低**：新版会容忍一次走棋产生的少量低分格点；若仍出现，说明画面变化不只来自落子，应关闭遮挡、动画特效或重新校准。
- **棋子数量超过上限**：说明本次完整棋盘识别受动画、光圈或遮挡干扰；等画面稳定后再次点击，仍失败则重新校准。
- **截图失败**：窗口模式下恢复并露出模拟器窗口；或在模拟器设置中打开 ADB 调试。
- **Pikafish启动或分析失败**：使用新版目录式构建并保留整个 `dist\XiangqiAssistant` 目录；错误信息会显示退出码和引擎最后输出，可据此判断 CPU 指令、DLL、NNUE 或安全软件问题。

每次点击“同步并分析”时，程序把实际参与识别和分析的画面覆盖保存到 `%APPDATA%\XiangqiAssistant\analysis_snapshot.png`。

点击主窗口“查看诊断”可直接查看最近一次同步分析快照、生成时间与完整路径；再点击“打开诊断目录”可在 Windows 资源管理器中打开保存位置。修改源码后必须重新执行 `build_exe.bat`；仍显示“开始辅助”或“同步当前棋盘”的 EXE 是旧构建。
